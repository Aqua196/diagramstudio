# 实验 9：集成测试报告

## 1. 范围与工具

集成测试关注模块之间的接口交互：每个用例至少跨两个模块，全部使用真实实现，不打桩。

| 层次                             | 工具                                        | 用例文件                                           |
| -------------------------------- | ------------------------------------------- | -------------------------------------------------- |
| 领域层各模块、命令行工具         | Vitest（jsdom）                             | `src/test/integration/io.integration.test.ts`      |
| 状态层 × 命令 × 插件             | Vitest（jsdom）                             | `src/test/integration/editing.integration.test.ts` |
| 协作适配器 × 协作服务            | Vitest（Node.js 环境）+ 真实 WebSocket 服务 | `src/test/integration/collab.integration.test.ts`  |
| 画布 × 插件形状 × 导出           | Playwright（Chromium）                      | `e2e/integration.spec.ts`                          |
| 协作服务的 HTTP / WebSocket 接口 | curl                                        | 手工探测，见实验报告                               |

运行：`pnpm vitest run src/test/integration`；`pnpm e2e e2e/integration.spec.ts`。
