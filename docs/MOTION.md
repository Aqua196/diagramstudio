# 动效设计与实现（2026-10-21）

> 目标：动效只用来**说明发生了什么**——东西从哪来、到哪去、刚才改了哪里，而不是装饰。
> 所有动效都是纯视图层：不写文档、不进撤销历史、不进协作广播；系统开启「减少动态效果」时一帧都不播，行为与无动效版本完全一致。

## 1. 原则

- **说明因果**：新节点从它的来源（父节点 / 连线另一端）长出来；折叠时子树收回父节点；撤销后被改动的节点闪一圈。
- **可打断、可改向**：补间中途文档又变了，从当前画面位置继续去新目标，不跳回起点；拖动随时接管；转场中按键/点击立即跳到结尾。
- **一次只有一个主角**：页面形变进行时画布自绘推迟到卡片落地；编辑器浮动条在画布长成之后才浮入。
- **节奏统一**：时长与曲线是令牌（`tokens.css` 的 `--dur-*`/`--ease-*`，画布侧镜像在 `motion/timing.ts`）。进场用减速曲线，退场更短并用加速曲线，弹簧只用于小位移的到达。

## 2. 一览

| 场景 | 效果 | 实现 |
| --- | --- | --- |
| 首页 → 编辑器（点卡片 / 新建 / 看示例） | 卡片缩略图形变成画布；示例图在画布上从根开始依次「自绘」，连线沿路径画出 | View Transitions 共享元素 + 画布 cascade |
| 编辑器 → 首页 | 画布缩回它在「最近的图表」里的那张卡片 | 同上，反向；卡片不在视口内时只做淡入淡出 |
| 主题切换 | 新主题从点击处以圆形扩散揭开 | View Transitions + `clip-path` |
| 首页首次打开 | 标题浮起，三张新建卡依次落下，卡内示例缩略图逐个节点拼出来 | CSS，每次会话一次 |
| 进入编辑器 | 四角浮动条从各自所在的边依次浮入，形状坞的按钮逐个摆上去 | CSS，`.ds-editor[data-enter]` 一次性 |
| Tab / Enter 加子主题、点「+」 | 新节点从父 / 源节点中心飞出并长大，略越过落点再回弹；连线全程贴着节点伸长；编辑框等它落位再浮现 | 画布引擎 enter |
| 悬停「+」 | 落点处先出现新节点的半透明虚影和一段虚线连接 | `QuickAddPreview` |
| 思维导图折叠 / 展开 | 子树一边缩小一边滑回父节点；展开时从被点的节点散开，兄弟节点同时让位 | 画布引擎 exit（残影）/ enter |
| 自动布局、对齐、分布、撤销 / 重做、协作者移动 | 节点滑到新位置，连线始终跟着；布局后图超出视野时镜头同时缩放到全图 | 画布引擎 move + `useCameraFollow` |
| 删除 | 节点原地缩小淡出，连线与标注一起淡出；撤销删除时原地弹回并重画连线 | 残影 + pop + draw |
| 撤销 / 重做 / 协作者改了内容 | 被改动的节点外圈闪一下 | `ds-fx-changed` |
| 选中 | 选中框从外圈收拢到位；选中单条连线时一颗光珠从起点跑到终点（示意方向） | CSS |
| 新节点开始编辑但在视野外 | 镜头平移到刚好露出它 | `useRevealEditing` |
| 菜单 / 弹层 / 气泡提示 / 对话框 / 提示条 | 从触发点长出；退场先收再走（更快）；提示条弹性上浮、下沉淡出 | CSS + Radix `data-state` |
| 上下文工具条 | 选中元素变化时从上方轻轻浮出 | CSS，按选择集 key 重播 |

## 3. 画布动效引擎

文件：`src/features/canvas/motion/`（`plan.ts` 规划、`tween.ts` 补间、`steps.ts` 各类动效落账、`fxBook.ts` 账本、`compose.ts` 合成、`cascade.ts` 自绘编排、`ghosts.ts` 残影、`hints.ts` 一次性提示、`canvasMotion.ts` 编排、`timing.ts` 时长与阈值）。

```
 文档变化 ─► useFlowSync：deriveNodes/deriveEdges（沿用未变对象与实测尺寸）
              │
              ▼
          CanvasMotion.reconcile(当前画面, 派生结果, lastChange)
              │  planMotion：比对 → moves / enters(origin) / exits(toward)
              │  steps：登记补间、动画类名、残影、描线
              ▼
          compose：起始位置覆盖 + className/CSS 变量 + 追加残影 ──► setNodes / setEdges（同一次提交）
              │
     rAF ─► Tweener 每帧只改「正在动」的节点位置（React Flow 自己按新位置重算连线）
     定时 ─► sweep：到期残影移除、动画类名摘掉（避免视口裁剪重挂载时重播）
```

要点：

- **只改视图**：补间写的是 React Flow 本地节点的 `position`，文档里一直是最终位置。所以导出、保存、协作拿到的永远是终态；撤销一次就回到原位（e2e `m4` 验证）。
- **何时播什么**由 `lastChange` 决定：本地命令与重做允许「从连线另一端飞出」；撤销与协作者改动只「原地出现」（撤销删除不该从邻居飞回来）；`set`（打开、导入后的位置回写）直接到位。
- **两段式改向**：思维导图加子主题是两次文档变化（加节点 → 合并进同一条历史的自动布局），中间可能没有一帧。规划总以「当前画面上的插值位置」为起点，所以第二次变化只是把补间改去新目标，动作连续。
- **残影**：退场的节点/连线保留 220ms，`aria-hidden` + `inert`、不可选不可拖，不计入全选、拖放目标与导出（`finishCanvasMotion()` 在导出前把一切动画跳到终点）。
- **只动形状本体**：长出/弹出缩放的是 `.ds-node-body`，连接锚点不随之缩放——React Flow 按锚点的屏幕位置测量，缩放中测到的位置会被记住，连线就接到节点里面去了（实测踩到过）。
- **自绘**只在打开示例、导入时播（`revealNext`），打开自己存的图不播；节点按「从根广度优先」依次弹出，连线在起点出现后开画、终点弹出时恰好画到；总时长 ≤ 约 1.1s，超过 80 个节点不播。

## 4. 页面转场

`src/features/shell/transition.ts`：

- 首页卡片缩略图与编辑器画布用同一个 `view-transition-name`，浏览器做位置/尺寸形变；方向不同交叉淡化节奏不同（进编辑器尽快让位给清晰的画布，回首页先让画布缩小快落位时再换成卡片图）。
- 转场的 update 回调期间浏览器暂停渲染，`requestAnimationFrame` 不会触发，只能用定时器等画布同步（踩过 4 秒超时的坑）。
- 同一时刻只有一个转场：开始前跳过旧的、清掉旧的类名与命名；`ready`/`updateCallbackDone` 被跳过时的 rejection 统一吞掉；页面不可见时不播；用户在转场中按键/点击会立即跳到结尾。
- 切换之后才该做的事（登记空白文档、导入成功提示、离开前立即落盘、把焦点交给新页面主体）都在 update 里同一刻执行，见 `docNav.ts`。
- 主题切换期间关闭所有颜色过渡，新画面直接是最终配色，圆圈里不会看到颜色慢慢变。

## 5. 界面层动效

`src/styles/motion.css`：菜单/弹层从 Radix 给出的触发点 `transform-origin` 长出；气泡提示按出现方向轻移；对话框与遮罩；提示条进出（`uiStore.dismissToast` 先标记 leaving 播 160ms 再移除）；退场动画期间 `pointer-events:none`，关闭中的菜单不挡下一次点击。位移一律用独立的 `translate`/`scale` 属性，与元素自身用于居中的 `transform` 叠加而不覆盖。

## 6. 减少动态效果与降级

- 系统开启「减少动态效果」：CSS 全局把时长压到 0.01ms，**延迟也清零、无限动画只播一次**、View Transitions 伪元素不动画；JS 侧（补间、残影、自绘、转场）统一经 `components/motion.ts` 的 `motionAllowed()` 关闭。e2e `m6` 用 MutationObserver 证明全程没有挂过任何 `ds-fx-*` 类名、没有起过转场。
- 不支持 View Transitions 的浏览器：直接切换，其余动效照常。
- 画面节点 > 200：画布引擎整体让路（500 节点性能门走这条）；一次位移 > 120 个节点直接到位；残影 > 60 个不留；连续两帧间隔 > 50ms（设备跟不上）补间直接跳到终点。

## 7. 性能约束

- 不给所有 `.react-flow__node` 外层加常驻 animation/transition/filter；动画类名只挂在参与的少数节点上，播完即摘。
- 选中连线的柔光由 CSS `drop-shadow` 改为一条半透明底线：全选几百条连线时不再有几百个滤镜。
- 一次选中超过 30 个节点不播选中框收拢动画。
- **顺手修掉了每次改文档所有连线消失一帧的老问题**：派生节点不带 React Flow 的 `measured`，React Flow 会清空全部锚点并整体重测，期间连线不渲染（编辑一个节点的文字会让 12/12 条连线卸载重建、连线工具条因此重建并丢焦点）。现在沿用上一帧的对象与实测尺寸（`derive.ts`），大图每条命令也少一轮全量测量。

## 8. 验证

- **单测**：`motion/plan.test.ts`（规划：滑动/长出来源/展开多层/折叠与删除收回/父链成环/自绘次序与时长上限）、`motion/tween.test.ts`（插值、让位、跳到终点、卡顿收尾）、`motion/canvasMotion.test.ts`（假时钟驱动完整对账→补间→清理、改向不跳回、残影、撤销提示圈、finish、StrictMode 重挂载）、`derive.test.ts`（对象沿用与 measured 保留）。
- **e2e**：`e2e/motion.spec.ts`（开启动效）——m1 页面形变 + 自绘、播完无残留、焦点；m2 每一帧采样新节点位置与连线终点，误差 < 2px（连线全程贴着节点）；m3 残影立即出现且不可达、计数正确；m4 动效不进历史；m5 连线工具条改样式不重建不丢焦点；m6 减少动态效果下零动效。其余用例默认以「减少动态效果」运行，截图、计数、axe 不受动画中间态影响。
- **逐帧检查**：开发时用两种方法截取中间帧——把 `performance.now` 与 CDP `Animation.setPlaybackRate` 同时放慢 5 倍逐帧截图；View Transitions 不受播放速率影响，改为在 `ready` 时暂停 `document.getAnimations()` 再逐个设 `currentTime`。
- **性能**：见 docs/PERFORMANCE.md §6。

## 9. 顺手修掉的问题

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 每次改文档所有连线闪一帧；连线工具条按一下就重建、丢焦点 | 派生节点不带 `measured`，React Flow 清空锚点重测 | `derive.ts` 沿用对象与实测尺寸 |
| 回首页前 500ms 内的编辑丢失，卡片缩略图是旧的 | 自动保存防抖回调在非编辑器路由下直接返回 | 离开编辑器 / 换文档前立即落盘 |
| 空白文档回收失效（加了转场后） | 转场把切换推迟一帧，「登记新空白文档」先于「回收上一份」执行 | 切换后才做的事放进 `after`，与切换同一刻执行 |
| 暗色无障碍用例实际在审亮色 | 先写主题再调用会清空 localStorage 的 `openEditor` | 主题在清空之后写入，并断言 `html.dark` |
| 协作光标、ER 鸟脚的描边颜色未定义 | 引用了不存在的 `--panel` 令牌 | 改为 `--surface` |
| 在首页双击卡片会在新打开的画布上多建一个节点 | 第二下点击落在刚挂载的画布上 | 进入编辑器头 500ms 不响应画布双击 |
| 加子主题 / 点「+」时新节点可能在视野外，看不见自己在打字 | — | 开始编辑时节点不在安全区内则平移镜头 |

## 10. 没做的

- 复制/粘贴的克隆体「从原件剥离」飞出：需要命令层把原件→克隆的映射传给动效层，收益一般。
- 首页最近列表增删改时的卡片重排动画（可用 View Transitions 做 FLIP）。
- 协作者头像入场、光标名签闲置收起。
