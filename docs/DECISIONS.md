## 2026-10-10 子代理执行方式（两次修订）

背景：SPEC §9 要求按阶段创建子代理。项目仓库没有可交接的远端，各阶段共享同一份持续演进的工作树与 node_modules。

第一选择：工作流 shared-VM 子代理。被系统拒绝：本会话是 SWE-2 会话，不支持 shared-VM agents。

第二选择：独立 VM 子代理 + git 分支交接。需要先建远端仓库，但 GITHUB_BURNER_PAT 已失效（API 返回 401 Bad credentials），无法在 Aqua196 下建仓库。

最终决定：总指挥直接按阶段顺序实现全部代码，保持每阶段的目录边界（IMPL_CONTRACT §1）、质量门（SPEC §10）与 Conventional Commits 小步提交完全不变；若用户后续创建 Aqua196/diagramstudio 公开仓库，阶段5 及之后可切回子代理并行（独立 VM + 分支交接）。

理由：不阻塞交付；阶段边界靠契约文件与逐阶段验收维持，而非执行者数量。

## 2026-10-10 Playwright 浏览器

背景：本机无 sudo，playwright 自带 chromium 可能缺系统库。

选择：优先自带 chromium；跑不起来时 playwright.config.ts 用 `channel: 'chrome'` 调系统 Chrome。

理由：仍是 Playwright 驱动，满足 SPEC 测试要求；系统 Chrome 无需系统依赖安装。

## 2026-10-10 交付方式

背景：SPEC 未指定代码托管位置，最终需让学生拿到含完整提交历史的代码。

选择：开发期只提交到本地 git（Conventional Commits）；完成时将仓库推送到用户 GitHub 账号下的公开仓库（若无权限则打包含 .git 的完整目录交付）。

理由：本地提交即可满足「小步提交」要求；最后统一交付避免中途打断。

## 2026-10-21 动效（详见 docs/MOTION.md）
- **画布动效做成纯视图层**：补间只改 React Flow 本地节点的 `position`/`className`，文档里一直是最终位置——撤销、保存、导出、协作拿到的都是终态，不需要任何「动画中」状态进命令或历史。
- **补间用 rAF 逐帧写位置，而不是给节点外层加 CSS transition**：CSS transition 只移动节点，连线会先跳到终点；逐帧写位置时 React Flow 每帧按新位置重算连线，线始终贴着节点。代价随节点数增长，所以画面节点 >200 时整体让路（500 节点性能门不受影响），一次位移 >120 个节点直接到位。
- **规划以「当前画面」为起点**：思维导图加子主题是两次文档变化（加节点 + 合并的自动布局），中间可能没有一帧；以画面上的插值位置为起点规划，第二次变化只是改目标，动作连续。
- **撤销/协作者改动不「从邻居飞出」**：撤销删除时节点应原地回来；只有本地新建与重做才从新连线另一端飞出。
- **自绘只在打开示例/导入时播**：自己存的图每次打开都重画一遍会烦；提示不是一次性消费，而是有 1.5s 有效期，StrictMode 的模拟重挂载也能播。
- **长出/弹出只缩放形状本体**：连接锚点若跟着缩放，React Flow 会在缩放中测量锚点并记住偏小的位置，连线接到节点里面去（实测踩到）。
- **派生节点沿用上一帧对象与 `measured`**：不带 `measured` 的新对象会让 React Flow 清空全部锚点重测，每次改文档所有连线消失一帧、连线工具条重建丢焦点；沿用后大图每条命令也少一轮全量测量。
- **页面转场用 View Transitions**：浏览器原生做共享元素形变，不引动画库；不支持时直接切换。转场把切换推迟到下一帧，所以「切换后才做的事」（登记空白文档、提示条、离开前落盘、焦点交接）统一放进 update 回调同一刻执行。加 1.5s 看门狗：个别环境动画时钟不走时直接跳到结尾，避免整页不响应。
- **e2e 默认以「减少动态效果」运行**：截图、计数、axe 不受动画中间态影响（此时应用与无动效完全一致）；动效本身由 `motion.spec.ts` 开启后单独验证，性能门也在开启动效下测。测试配置里为测真实帧耗加的 `--disable-frame-rate-limit --disable-gpu-vsync` 会让无头 Chromium 在 View Transition 之后不再触发 rAF，相关用例改为不经转场进入编辑器后再打开动效。

## 2026-10-22 形状坞展开说明、形状内编辑文字
- **形状坞悬停整体向右展开名称与快捷键**，代替逐个按钮的气泡提示：一眼看全，不用挨个悬停；停留 120ms 才展开，鼠标划过时不乱弹；键盘移入（`:focus-visible`）同样展开。名称就是按钮的无障碍名，快捷键不朗读。
- **文字编辑改到形状自己的文字位里**：旧做法是在节点上盖一个统一的白色方框，菱形、圆、圆柱编辑时都变成方块，看不出在给哪个形状写字。现在插件渲染时把画布提供的编辑框放进原本显示文字的位置（`ShapeRenderContext.editor`，可选字段，插件契约不破），编辑框透明、继承形状的字号/字重/颜色/对齐与内边距，随节点移动和缩放；正在编辑的形状描主题色并沿轮廓发光（同一时刻只有一个，滤镜不影响整图性能）。顺带去掉了「新节点落位后再显示编辑框」的计时逻辑——编辑框本来就跟着节点走了。
- **Enter 提交时排除输入法组字**（`isComposing`）：以前用中文输入法按 Enter 确认候选词会直接提交文字。
- **（10-25 修正）坞的展开改为只动裁剪、不动排版**：第一版逐帧过渡二十多个元素的 `max-width`/边距，实测展开先瞬间跳 14px（内边距没进过渡）、停 120ms、两帧内猛拉 70px 再慢慢爬，提示行撑高还让整条坞上移 8px，用户反馈卡顿。现在名称、快捷键、提示始终排在图标右边，收起时坞体和按钮就是图标列那么宽，文字溢出在外、被 `clip-path` 裁掉（命中区一并裁掉）；悬停时坞体一次性换成内容宽度，之后只过渡裁剪区和独立背景板的宽度，收起时宽度等裁剪收完再换回（`allow-discrete`）；提示行收起时就是分隔线，高度不变。展开曲线平滑，高度与位置全程不动，4 倍 CPU 降速下排版耗时减半。

## 2026-10-25 体检修复（不加功能）
- **浏览器返回键回首页**：首页与编辑器共用一个网址，以前进编辑器不留浏览器历史，按返回直接离开网站。现在进编辑器时压一条历史（网址不变），返回 / 前进在两页之间切换；「返回首页」按钮有这条历史时就走 `history.back()`，和返回键是同一件事。刷新后仍回上次的图表，并在下面垫一条首页历史。
- **启动路由在渲染前决定**（`features/shell/docs/boot.ts`，`main.tsx` 里调用）：以前 `route` 默认是编辑器、挂载后才判断要不要跳首页，首次访问会先挂一个空编辑器再跳走。
- **窄屏页能回首页**：手机上点「看示例」进入「窗口有点窄」后没有出口，刷新也回不去（上次打开的图表会被恢复）。现在有「返回首页」按钮，触屏设备文案改为「请在电脑上打开」。
- **非 https 的局域网地址白屏**：`crypto.randomUUID` 只在安全上下文里有，用 http + IP 打开（同网演示的典型用法）会直接报错白屏；`createId` 退回 `getRandomValues` 拼 UUID v4，补单测。
- **协作服务未部署时如实说明**：在线版以前点「开启协作」会一直「连接中」并反复报连接错误，提示的还是开发命令。现在没配 `VITE_COLLAB_WS` 且不是本机访问时，分享弹层直接说明并不给开启按钮，`?room=` 链接提示后照常打开。
- **首屏瘦身**：yjs（约 90KB）只在开启协作时加载；截图库只在导出时加载；数据校验从完整版 zod 换成 `zod/mini`（同样的校验与中文报错，体积小得多）。首屏 JS 由 888KB（gzip 284KB）降到 715KB（gzip 233KB）。zod 包里不规范的注释警告在构建配置里按类别过滤，构建恢复零警告。
- **代码格式统一**：56 个文件与 `.prettierrc` 不一致（部分是为卡 200 行上限把代码挤成长行）。统一格式后超限的三个文件按职责拆分：流程图形状几何移到 `shapePaths.tsx`（填充/描边/线宽/虚线由外层 `<g>` 统一给，像素级对比与旧版一致），思维导图节点渲染移到 `mindmapNode.tsx`，ER 字段拖动状态抽出类型。
- **下载统一走 `downloadBlob`**（`src/io/export.ts`）：原来有两份下载函数——JSON/Mermaid 点击后立刻回收 blob 地址（Firefox 上可能取消下载），PNG/SVG 从不回收（每次导出泄漏一份图片）；现在统一延后 10 秒回收。文件名统一走 `fileName`，标题为空时用默认名（以前 PNG/SVG 会得到「.png」这样的隐藏文件）。`export.ts` 里从没被调用的 `exportJsonFile`/`exportMermaidFile` 删除。
