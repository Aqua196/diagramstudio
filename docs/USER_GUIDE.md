## 1. 安装与运行

**不想安装**：直接打开在线版 <https://aqua196.github.io/diagramstudio/>。除实时协作外功能完全一致；图表保存在你当前浏览器的本地存储里，换浏览器或清除网站数据会丢失，重要的图请「导出 → JSON 工程文件」备份。

**本地运行**：

要求：Node 20+、pnpm 10+（`packageManager` 已锁定 `pnpm@10.34.6`，可用 `corepack enable` 自动对齐）。

```bash
pnpm install        # 装依赖（装完即完全离线可用）
pnpm dev            # 启动编辑器 → http://localhost:5173
pnpm dev:collab     # 需要协作时：同时启动协作服务 ws://127.0.0.1:1234 与前端
```

其他脚本：`pnpm build`（构建 dist）、`pnpm preview`（预览构建）、`pnpm test`（单测）、`pnpm test:coverage`（覆盖率）、`pnpm e2e`（Playwright）、`pnpm lint` / `pnpm typecheck` / `pnpm format`。

> 浏览器窗口宽度需 ≥1024px，否则整屏提示「窗口有点窄」。

## 2. 界面导览

```text
┌──────────────────────────────────────────────────────────────────┐
│ [‹ 标 文档名 · 类型 · 已自动保存]                [头像][分享][导出][⋯] │
│ ┌─┐                                                              │
│ │↖│   选择 / 抓手                                                 │
│ │▭│   常用形状：点击添加，也可拖到画布                                │
│ │◇│                    ┌ 选中后出现的上下文工具条 ┐                 │
│ │…│   更多形状          │ 颜色 字号 加粗 编辑 … 删除 │                 │
│ │▦│   示例模板          └──────────────────────────┘                 │
│ │✦│   自动整理                    [+] 节点 [+]                       │
│ └─┘                                                              │
│ [撤销 重做 │ − 100% + 适应]    💡 上手提示（可关闭）     [小地图 设置 ?] │
└──────────────────────────────────────────────────────────────────┘
```

- **画布铺满全屏**，界面都是悬浮在四角的小卡片：
  - **左上**：返回首页、文档名（点一下就能改名）、图类型与「已自动保存」。
  - **右上**：协作头像、「分享」「导出」，以及「更多」菜单（导入 JSON / Mermaid、浅色 / 深色 / 跟随系统、键盘快捷键、返回首页）。
  - **左侧形状坞**：当前图类型的常用形状，**点一下就放到画面中央并进入打字**，也可以拖到指定位置；「更多形状」「示例模板」「自动整理」也在这里。
  - **左下**：撤销 / 重做（悬停显示「撤销：×××」）、缩放（点百分比回到 100%）、适应画面。
  - **右下**：小地图开关、画布设置（点阵网格 / 吸附 / 整理方向）、快捷键面板。
  - **底部居中**：上手提示，随图类型和「有没有选中东西」变化，点 ✕ 关闭后不再出现。
- **上下文工具条**：选中什么，它就出现在什么上方（见 §3）。
- **首页**：三张新建卡（示例缩略图 + 「新建空白」「看示例」）和「最近的图表」缩略图网格；卡片右下「⋯」可重命名、创建副本、删除（需确认）。

## 3. 基本操作

### 添加节点（三种方式，加完都会直接进入打字）

| 方式 | 操作 |
| --- | --- |
| 形状坞 | 点左侧形状 → 出现在画面中央（与已有节点错开） |
| 四周「+」 | 选中一个节点，点它四周的「+」→ 在该方向接一个**已经连好线**的新节点；已连线的一侧不显示「+」 |
| 双击 / 拖入 | 双击画布空白处放一个默认形状；或把形状从左侧拖到任意位置 |

流程图里，「开始 / 结束」「判断」之后用「+」会自动接一个「处理」，其余形状接同一种形状。

### 画布与视图

| 操作 | 方式 |
| --- | --- |
| 平移 | 按住空格拖动 / 鼠标中键拖动 / 触控板双指 / H 切抓手工具 |
| 缩放 | Ctrl/Cmd+滚轮；左下 + / −；点百分比回到 100%；Ctrl/Cmd+0 适应画面（范围 10%–400%） |
| 网格与吸附 | 右下「画布设置」：点阵网格（24px）与吸附（步长 12px，默认开） |
| 小地图 | 右下第一个按钮，默认关闭 |

### 选择与编辑

| 操作 | 方式 |
| --- | --- |
| 选择 | 单击；Shift+单击多选；空白处拖框选 |
| 移动 | 拖动（显示对齐参考线并吸附到其他节点边缘/中心）；方向键 1px、Shift+方向键 10px |
| 缩放节点 | 选中后拖四角/四边的小方块夹点（有最小尺寸） |
| 编辑文字 | 双击、Enter 或 F2；Shift+Enter 换行；Esc 取消；点空白提交 |
| 剪贴板 | Ctrl+C/X/V：粘贴偏移 24px 且保留所选节点间的连线；Ctrl+D 创建副本；Delete 删除 |
| 右键菜单 | 带图标与快捷键，随选中对象变化；空白处右键可全选、适应画面 |

### 上下文工具条

| 选中 | 可做的事 |
| --- | --- |
| 一个节点 | 颜色 · 字号（小/中/大）· 加粗 · 编辑文字 · 插件专属按钮（思维导图「添加子主题/同级主题」、ER「添加字段」）· 「⋯」里的位置尺寸、边框粗细、虚线边框、置顶/置底、创建副本 · 删除 |
| 多个节点 | 已选数量 · 统一颜色 · 左/中/右/顶/中/底对齐 · 水平/垂直等距（≥3 个）· 删除 |
| 一条连线 | 曲线/折线/直线 · 终点箭头 · 虚线 · 标注 · ER 起点/终点基数 · 删除 |

### 连线

| 操作 | 方式 |
| --- | --- |
| 最快 | 选中节点点四周「+」，新节点和连线一起生成 |
| 手动 | 悬停节点出现四个圆点，从任一点拖到目标节点 |
| 落空新建 | 拖到空白处松手 → 弹出「接一个什么形状？」→ 新建节点并自动连好 |
| 标注 | 双击连线，或选中后点工具条「标注」 |
| 重连 | 拖动连线端点到别的节点 |

### 撤销与重做

- Ctrl+Z 撤销、Ctrl+Shift+Z（或 Ctrl+Y）重做；按钮悬停显示将撤销的操作名（如「撤销：移动 3 个元素」）。
- 拖动一次 = 一条历史；连续打字 600ms 内合并为一条；多选统一改色是一条；历史上限 200 条。
- 自动整理、粘贴、导入各自是一条命令，可整体撤销。

| 键 | 功能 | 键 | 功能 |
| --- | --- | --- | --- |
| V | 选择工具 | Delete | 删除所选 |
| H | 抓手工具 | `[` / `]` | 置底/置顶 |
| Ctrl+A | 全选 | Ctrl+0 | 适应画面 |
| Ctrl+C / X / V | 复制/剪切/粘贴 | Ctrl+ = / − | 放大/缩小 |
| Ctrl+D | 创建副本 | Shift+L | 自动整理 |
| Ctrl+Z | 撤销 | ? | 快捷键面板 |
| Ctrl+Shift+Z / Ctrl+Y | 重做 | Esc | 取消选择 / 取消文字编辑 / 关闭弹层 |
| 方向键 | 微调 1px（Shift=10px） | Enter / F2 | 编辑文字 |
| Tab（思维导图） | 添加子主题并直接打字 | Enter（思维导图） | 添加同级主题并直接打字 |

## 5. 三种图用法

### 流程图

- 形状：处理、开始/结束、判断、输入输出、子流程（常用 5 个在形状坞），数据库、文档、连接点、起止（双圈）、便签在「更多形状」里，全部 SVG。
- 新连线默认是带圆角的折线；选中连线可改曲线/直线。
- 自动整理用 dagre（方向在右下「画布设置」里选从上到下 / 从左到右）；支持 Mermaid 导入导出（见 §7）。

![示例「用户登录流程」：选中节点后的工具条与四周「+」](screenshots/guide/02-flowchart-template.png)

### 思维导图

- 新建空白导图自带「中心主题」。选中任意主题按 **Tab** 加子主题、**Enter** 加同级主题——新主题会自动选中并进入编辑，直接打字、回车提交，再回车就是下一个同级。
- 不选中任何主题时按 Tab，也会给中心主题加子主题；形状坞的「主题」按钮同理（挂到所选主题下）。
- 每次变动自动左右交替布局；一级分支自动轮换配色，连线跟随分支色。
- 折叠：悬停或选中主题时，外侧出现「−」，点一下收起整支；收起后显示子主题数，再点展开。
- 把一个主题拖到另一个主题上可改变层级（不允许拖进自己的子树）；Delete 删除整支。

![示例「软件工程知识点」](screenshots/guide/03-mindmap-template.png)

### ER 图

- 实体是表格节点：表头 = 实体名，行 = 字段（PK/FK 标记、名称、类型）。新建实体自带 `id` 主键。
- 行内直接改字段名/类型；「＋ 添加字段」或工具条「添加字段」加一行；悬停字段行出现拖动柄与「×」；点 PK 列循环切换 主键 → 外键 → 无。
- 双击表头改实体名；弱实体为双层边框。
- 关系：从实体边缘的圆点拖到另一实体，或用四周「+」。新关系默认「1 对 0..N」，选中后在工具条改两端基数（1、0..1、N、0..N），画成鸟脚符号并标注文字。

![示例「图书管理系统」：选中关系的工具条](screenshots/guide/04-er-template.png)

## 6. 文档管理

- **自动保存**：编辑即存 localStorage（防抖 500ms），左上显示「已自动保存」；Ctrl+S 立即保存。
- **新建**：首页每张卡都有「新建空白」和「看示例」。内置示例：流程图「用户登录流程」、思维导图「软件工程知识点」、ER 图「图书管理系统」；编辑器左侧「示例模板」里也能打开。
- 新建空白后**什么都没画就离开**，这份空文档会被自动回收，不会出现在「最近的图表」里。
- **重命名/副本/删除**：首页卡片「⋯」菜单，删除需确认；编辑器里点文档名即可改名。
- 空画布有一句上手提示和「载入示例」按钮。

## 7. 导入与导出

点右上「导出」，在对话框里选格式：

| 格式 | 说明 |
| --- | --- |
| PNG 图片 | 清晰度 1x/2x/3x；背景白色/透明/点阵；可加「图框与标题栏」 |
| SVG 矢量图 | 背景与图框同上 |
| JSON 工程文件 | `标题.json`，完整文档，可再导入 |
| Mermaid 文本 | `标题.mmd`，流程图子集（其他类型置灰） |

「图框与标题栏」：外边框 + 右下角工程制图标题栏（图名/作者/日期/版本/比例），作者与版本在对话框里填。导出时连接点、夹点、工具条、折叠钮等交互件不会出现在成品里。

导入在右上「更多」或首页右上「导入」：

| 格式 | 说明 |
| --- | --- |
| JSON | zod 校验；失败给出具体中文原因（如「字段 nodes.n1.size.w 应为数字」）；悬空连线报「连线的起点不存在」 |
| Mermaid | 选择 `.mmd`/文本文件，dagre 自动摆位、连线用流程图默认折线；不认识的行跳过，完成后提示跳过了几行 |

![导出对话框：格式卡片 + 图片选项](screenshots/guide/05-export-dialog.png)

![Mermaid 导入结果](screenshots/guide/07-mermaid-import.png)

Mermaid 子集：`graph/flowchart` + TD/TB/LR/RL/BT；节点 `A[矩形]`、`A(圆角)`、`A{判断}`、`A([起止])`、`A[(数据库)]`、`A[/输入输出/]`、`A[[子流程]]`、`A((连接符))`；连线 `-->`、`---`、`-.->`、`==>`、`<--`、`<-->`；标签 `-->|文字|` 与 `-- 文字 -->`；链式 `A --> B --> C`。

## 8. 协作分享

1. 先 `pnpm dev:collab` 启动协作服务（默认 ws://127.0.0.1:1234，可用 `VITE_COLLAB_WS` 覆盖）。
2. 右上点「分享」→「开启协作并生成链接」，链接自动复制，弹层里也能再次复制。
3. 同伴打开链接即自动进房：双方文档实时同步，可看到对方的彩色光标与昵称（如「用户42」）；弹层显示连接状态与在线成员，右上显示头像。
4. 弹层里点「结束协作」即回到单机模式——协作失败/关闭时全部编辑功能不受影响；未连上服务时弹层会提示先启动 `pnpm dev:collab`。

限制：房间存内存无鉴权；协作中撤销不进入对方历史；昵称自动生成不可改。

## 9. 主题与外观

- 浅色（暖白画布 + 靛蓝强调）/ 深色（中性炭灰）两套设计令牌，默认跟随系统；右上「更多」里切换并记住（`localStorage: ds:theme`），首页右上也有快捷切换。
- 节点 7 色：白、灰、青、蓝、黄、红、紫，每色有亮/暗两版底色与同色相描边——同一份文档切主题自动换色。
- 字体：界面 Inter + 中文系统字体（苹方/微软雅黑/思源黑体），本地打包，离线可用。

## 10. 常见问题

**Q：断网还能用吗？**
A：可以。装完依赖后所有资源本地化，文档在浏览器 localStorage；只有协作需要本机服务。

**Q：文档存在哪？会丢吗？**
A：localStorage（键 `ds.docs.v1` + `ds.docIndex.v1`）。清浏览器数据会丢——重要文档请「导出 JSON」备份。

**Q：导入 JSON 报错怎么看？**
A：错误信息是中文且带字段路径，例如「字段 nodes.n3.style.strokeWidth 应为数字」「连线的终点 n9 不存在」，按提示修正文件即可。

**Q：Mermaid 为什么提示「跳过 N 行」？**
A：解析器只支持子集（见 §7），注释与不识别的语句会被跳过；其余内容照常导入。

**Q：撤销怎么只退一步？**
A：拖动/打字的过程态不记历史，一步=一条命令；600ms 内的连续打字合并为一条。历史上限 200 条。

**Q：协作时对方删了我正在改的元素？**
A：远端合并不进本地历史；撤销时若目标元素已被删除，该补丁自动跳过，其他部分正常回退。

**Q：窗口太窄为什么只显示一句话？**
A：桌面优先设计，<1024px 不渲染错乱界面，只提示把窗口拉宽。

**Q：底部的提示条能关掉吗？**
A：能，点提示条右侧 ✕，之后不再显示（记在本机浏览器里）。

**Q：以前顶栏能切换图类型，现在去哪了？**
A：去掉了。那个开关会把当前文档整个改成另一种图，节点会变成看不懂的方框，误触代价太大。现在图类型在新建时决定，想换类型请新建一份。
